# Interaction recording (experimental)

Recording is disabled by default. Enable metadata-only recording with DOMSTRIDE_RECORD_DIR=tmp/domstride-recordings. Add DOMSTRIDE_RECORD_HTML=1 to opt into raw HTML snapshots. Native Session also accepts recording_directory: and recording_html: options. Each persistent worker creates its own private directory (0700) and files (0600). Capybara reset closes the recording; subsequent workers create a fresh recording.

events.jsonl starts with schema_version 1 header, then interaction rows containing protocol sequence, optional explicit BDD wrapper step_sequence, command kind, elapsed wall time, status and structural target paths before/after. Paths are zero-based child-element indexes starting at documentElement. A detached or replaced target has no after path. Record mutating commands, native text assertions/waits, script calls and explicit clock/settle operations; Capybara query retries are not recorded as assertions. Batch is one event. Native visit is represented by mount; Rack errors before mount are not captured. No selectors, command arguments, result payloads, URLs, or exception messages are serialized in metadata. BDD linkage uses the explicit wrapper sequence, not automatic Gherkin step interception.

With HTML enabled, capture before targeted commands and after command checkpoints, including failed worker commands where possible. New snapshots contain raw body markup with its structural path (older recordings used documentElement.outerHTML), not a screenshot or browser rendering. Snapshots clone the document and mirror live input/textarea/select state into the clone; password/file/hidden input value attributes are removed, but other HTML may still contain secrets. No sanitization or guaranteed redaction: HTML may contain secrets, scripts, tokens or personal data. Treat all snapshots as sensitive, never execute them or publish them. The future HTML viewer must use inert rendering and disallow network/script execution.

Bounded recording: 1000 events, 256 KiB per snapshot, 16 MiB total HTML per worker. Omission is explicit when limits are exceeded. Capture failures do not alter worker command success/failure; recording write errors stop recording and warn. Initialization can fail if the destination is inaccessible. Recording changes execution cost; disable it for baseline performance measurements. Timing includes capture overhead. No time-travel execution, network replay, browser video or visual layout parity. Export one recording with bundle exec domstride replay RECORDING_DIRECTORY [OUTPUT_HTML]. The local HTML viewer supports before/after, target highlight, previous/next, and either sidebar position. It reconstructs a limited allowlisted DOM preview, parses body markup in a detached inert template, reconstructs only safe elements and drops original styles, scripts, links and resource attributes, and enforces a restrictive CSP. No app requests or code execution. BATCH-009 expands to suite-level reporting and framework mapping. Output is private, refuses overwrite, and remains sensitive.
