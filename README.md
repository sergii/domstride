# Domstride

Fast interactions. Real behavior.

Experimental browserless-first interaction testing for Ruby applications. Inspired by [rails-jsdom](https://github.com/jakehow/rails-jsdom). The initial prototype is independently implemented; no upstream source is copied.

Status: pre-alpha. The first milestone measures a persistent Ruby-to-JavaScript worker with a DOM interaction example. Rails, Turbo, Stimulus and browser parity are subsequent milestones.
